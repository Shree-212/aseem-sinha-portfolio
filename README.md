# Aseem Sinha Portfolio

A stunning single-page portfolio website built with Next.js, React, and Three.js, featuring interactive 3D animations and a beautiful pastel color scheme.

## Features

- 🎨 Beautiful pastel color scheme with bright, modern aesthetics
- 🌟 Three.js-based 3D background animations
- 💫 Smooth scroll animations using Framer Motion
- 📱 Fully responsive design
- ⚡ Built with Next.js 15 and React 19
- 🎯 Custom CSS modules (no Tailwind)
- 🚀 Optimized performance

## Tech Stack

- **Framework**: Next.js 15
- **UI Library**: React 19
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Animations**: Framer Motion
- **Styling**: CSS Modules
- **Language**: TypeScript

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

```
├── app/                    # Next.js app directory
│   ├── layout.tsx         # Root layout
│   ├── page.tsx           # Home page
│   └── globals.css        # Global styles
├── components/            # React components
│   ├── Navigation.tsx     # Navigation bar
│   ├── Background3D.tsx   # 3D background
│   ├── Hero.tsx          # Hero section
│   ├── About.tsx         # About section
│   ├── Research.tsx      # Research section
│   ├── Education.tsx     # Education section
│   ├── Experience.tsx    # Experience section
│   ├── Teaching.tsx      # Teaching section
│   └── Contact.tsx       # Contact section
└── public/               # Static assets
```

## Sections

1. **Hero** - Eye-catching introduction with animated title
2. **About** - Biography and research overview
3. **Research** - Publications and work in progress
4. **Education** - Academic journey and credentials
5. **Experience** - Professional background
6. **Teaching** - Teaching experience and mentorship
7. **Contact** - Contact information and references
